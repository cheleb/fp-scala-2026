## FP Programming exercises 2026

This repository contains exercises for functional programming in 2026. The exercises are designed to help you practice and improve your functional programming skills.

4 modules are inluded in this repository:

- raw: pure scala exercises
- cats: exercises using the cats library
- zio: exercises using the zio library
- kyo: exercises using the kyo library

### Usage

The following command will run all the exercises in the repository:

```bash
sbt test

```
